## Projeto em destaque

### Campus Flow — IME-USP

[Repositório](https://github.com/Henriquewtd-cyber/Campus-Flow)

Plataforma institucional desenvolvida para centralizar informações do IME-USP, atualmente distribuídas entre e-mails, murais e diferentes canais de comunicação.

Projeto autoral selecionado pelo Prêmio Pipa 2026, desenvolvido individualmente e com previsão de publicação como plataforma ativa do instituto em dezembro de 2026.

O objetivo é facilitar o acesso a eventos, oportunidades, avisos e prazos para uma comunidade de aproximadamente 2.000 pessoas.

Uma pesquisa com 135 pessoas da comunidade identificou que:
- 51,1% já perderam algum evento ou prazo por não terem visto a informação a tempo.
- 89,6% consideram uma plataforma centralizada útil ou muito útil.

**Principais funcionalidades**
- Feed de eventos com filtros por categorias, públicos e áreas.
- Páginas individuais para consulta de informações.
- Painel administrativo para criação, edição e publicação de eventos.
- Painel dinâmico para TVs institucionais, com QR Codes.
- Automação de coleta e estruturação de informações de e-mails com IA, n8n e FastAPI, mantendo a revisão humana antes da publicação.

**Stack**

`React` `Next.js` `TypeScript` `Tailwind CSS`  
`FastAPI` `Python` `Pydantic` `PostgreSQL`  
`Docker` `n8n` `Groq API`
